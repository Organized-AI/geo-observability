## Name and domain

A project is one brand on one main domain. You can rename it at any time. List any extra domains you own on your brand in [Competitors and aliases](/docs/competitors-and-aliases/), so they count toward [cited rate](/docs/metric-cited-rate/).

## Schedule

Each project runs on one of three schedules:

| Schedule | What happens |
|---|---|
| Daily | A pass every day at 06:00 UTC. This is the default. |
| Weekly | One pass a week. |
| Paused | No scheduled passes. |

A **pass** runs every active prompt once on every enabled engine for every selected country. Daily passes give smoother trends and catch changes sooner. Weekly passes use about a seventh of the [usage](/docs/usage/).

Pausing keeps all your history. Reports still work, they just stop getting new data.

## Run a pass now

You can start a pass by hand at any time, for example after adding new prompts. The progress bar shows how many answers are done, running and failed. A manual pass uses usage like any other.

## Daily jobs

Two things happen each day regardless of when you look:

- **06:00 UTC**: the scheduled pass for daily projects.
- **09:00 UTC**: [insights](/docs/overview/#insights) are written by comparing the latest period with the previous one.

## Who can change settings

Owners and editors can change settings. Viewers can see them but not change them. See [Logins and roles](/docs/logins-and-roles/).
