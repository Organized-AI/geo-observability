    Prompt performance

    Prompt performance puts every prompt in one table, so you can see which questions you win and which you lose.

    #The columns

    Column Meaning
    Prompt The question, with its topic
    Visibility Share of this prompt's answers that name you
    Position Your average rank when named
    Sentiment Average sentiment when named
    Answers How many answers this row is based on
    Best engine The engine where you do best for this prompt
    Worst engine The engine where you do worst

    All columns follow the filter bar.

    #How to use it

    • Sort by visibility, lowest first. These are the questions where buyers don't hear about you. Read a few chats for each.
    • Look at best and worst engine together. If you're named every time on Perplexity and never on ChatGPT, compare the sources each one cited. The difference usually points to the fix.
    • Watch the answer count. One prompt on four engines in one country over seven days is 28 answers. A single answer changes visibility by almost four points.
    • Spot prompts that never move. A prompt where every brand scores zero may be worded so that assistants don't recommend brands at all. Reword it or archive it.

    #Prompts won and lost

    The daily insights call out prompts you started or stopped appearing in compared with the previous period. They're the quickest way to spot a change without scanning the table.
