    Agencies

    Agencies: getting started

    GEO Observability works well for agencies that track AI visibility for several clients. This page explains how clients are organised and what agency staff can see.

    #Workspaces and projects

    • A workspace holds one client's data, people, usage and API keys.
    • A project inside it is one brand on one website. A client with two brands, or separate sites per country, can have several projects, within the workspace's plan limits.

    Keeping each client in its own workspace means their people, their keys and their usage stay separate.

    #What agency staff see

    People marked as agency staff see every client workspace in the workspace switcher. Client contacts see only their own workspace.

    #Setting up a new client

    1. Open the client's workspace from the workspace switcher.
    2. Create a project with the client's brand name and main domain.
    3. Follow the Quickstart: brand profile, topics, prompts, competitors, engines and countries.
    4. Check that no engine is running on the stub channel. Stub answers are sample text and count in the metrics. See Engines reference.
    5. Finish onboarding to start the first pass.

    #Giving the client access

    You have two options:

    • Sign-in access. Set the workspace's company email domain so the client's people join as viewers the first time they sign in with an emailed link, or add them by hand. See Logins and roles.
    • Share links. Send a read-only link to a saved view. No sign-in needed, and it expires. See Saved views, sharing and exports.
