    Metrics: Position

    Position tells you how early in an answer you're named, when you're named at all.

    #Definition

    Position = your average rank in answers that name you. Rank 1 means you were the first tracked brand named. Lower is better.

    Rank follows the order in which brands first appear in the answer text. If an answer mentions Brightbean, then you, then Brightbean again, you're rank 2.

    #Example

    You're named in three answers, at ranks 1, 2 and 4. Position is (1 + 2 + 4) ÷ 3 = 2.3.

    #Reading it

    • Position only averages answers that name you. If you drop out of the answers where you used to rank 5th, your position improves while your visibility falls. Always read it next to visibility.
    • Rank counts tracked brands. Untracked brands named before you don't push your rank down.
    • First appearance isn't always "recommended first". An answer that opens with "Unlike Fernhill, Brightbean…" ranks Fernhill 1. Read the chats when a number surprises you.
    • When comparing periods, a falling number is good news.
