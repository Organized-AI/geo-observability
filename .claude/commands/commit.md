# Smart commit
1. Run /verify first.
2. Show `git status` and `git diff --stat`.
3. Write a conventional commit message (feat/fix/docs/refactor/test/chore).
4. Author and committer must be Jordan Hill; no Co-Authored-By or AI trailers.
5. Confirm before committing. Don't push unless asked.
